# ML Labs — набор лабораторных работ

Репозиторий содержит набор ноутбуков и данных по курсу машинного обучения и NLP, подготовленных для учебных лабораторных работ.

Содержимое
- `data_ruslan.csv` — датасет (если присутствует).
- Несколько Jupyter ноутбуков с лабораторными работами: NLP, кластеризация, XAI и т.д.

Как использовать
1. Установите Python 3.8+ и Jupyter:

```
python -m pip install --upgrade pip
pip install jupyterlab pandas scikit-learn matplotlib seaborn nltk
```

2. Запустите Jupyter в папке репозитория:

```
jupyter lab
```

3. Откройте нужный ноутбук (файлы `.ipynb`).

Примечания
- Ноутбуки могли использовать дополнительные библиотеки (например, transformers, torch). При возникновении ошибок устанавливайте зависимости по необходимости.
- Если хотите, могу добавить `requirements.txt` или `environment.yml` для воспроизводимости.
