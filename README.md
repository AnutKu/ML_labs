
# ML Labs — набор лабораторных работ

Сборник ноутбуков по машинному обучению и обработке естественного языка. Все работы выполнены в рамках курса "Машинное обучение" НИЯУ МИФИ.

Навигация:

- [ML_lab1.ipynb](ML_lab1.ipynb) — классификация нарушений сна, предобработка, baseline модели.
- [ML_lab2.ipynb](ML_lab2.ipynb) — подбор гиперпараметров и сравнение моделей.
- [ML_lab_claster (1).ipynb](ML_lab_claster%20(1).ipynb) — кластеризация по профилям сна.
- [ML_lab_claster_2_part.ipynb](ML_lab_claster_2_part.ipynb) — продолжение кластеризации и визуализации.
- [ML_lab_cross.ipynb](ML_lab_cross.ipynb) — кросс-валидация и оценка устойчивости моделей.
- [NLP_Lab_1_ready.ipynb](NLP_Lab_1_ready.ipynb) — вводная по NLP: regex, токенизация.
- [NLP_Lab_1_ruslan_sent.ipynb](NLP_Lab_1_ruslan_sent.ipynb) — вариант с примерами и комментариями.
- [LAB_2_FROM_RUSLAN_SENTIMENT.ipynb](LAB_2_FROM_RUSLAN_SENTIMENT.ipynb) — анализ тональности, векторизация, линейные модели.
- [NLP_Lab_2_Ruslan.ipynb](NLP_Lab_2_Ruslan.ipynb) — продвинутый анализ тональности и кластеризация текстов.
- [NLP_Lab_3.ipynb](NLP_Lab_3.ipynb) — суммаризация и машинный перевод, примеры TextRank/sumy.
- [LAB_3_NLP_done (2).ipynb](LAB_3_NLP_done%20(2).ipynb) — суммаризация абстрактов, препроцессинг и лемматизация.
- [XAI.ipynb](XAI.ipynb) — объяснимость моделей с помощью SHAP; примеры глобальных и локальных объяснений.
