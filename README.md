
# ML Labs — набор лабораторных работ

Сборник ноутбуков по машинному обучению и обработке естественного языка. Все работы выполнены в рамках курса "Машинное обучение" НИЯУ МИФИ.

Краткие описания ноутбуков
- `ML_lab1.ipynb`: Классификация нарушений сна — предобработка признаков и обучение базовых классификаторов (логистическая регрессия, kNN и др.).
- `ML_lab2.ipynb`: Сравнение моделей и подбор гиперпараметров для задачи классификации; оценка качества (F1, accuracy) и анализ ошибок.
- `ML_lab_claster (1).ipynb`: Кластеризация профилей сна — исследование сегментов пользователей по признакам сна и образу жизни.
- `ML_lab_claster_2_part.ipynb`: Продолжение работы по кластеризации: визуализация и интерпретация групп.
- `ML_lab_cross.ipynb`: Эксперименты с кросс-валидацией и оценкой устойчивости моделей классификации.
- `NLP_Lab_1_ready.ipynb`: Вводная работа по NLP — регулярные выражения, токенизация и базовые текстовые операции.
- `NLP_Lab_1_ruslan_sent.ipynb`: Практика регулярных выражений и базовых приёмов NLP (вариант с комментариями).
- `LAB_2_FROM_RUSLAN_SENTIMENT.ipynb`: Анализ тональности и базовые подходы к векторизации и обучению линейных моделей.
- `NLP_Lab_2_Ruslan.ipynb`: Анализ тональности и кластеризация текстов — частотные и векторные методы, обучение и оценка моделей.
- `NLP_Lab_3.ipynb`: Суммаризация и машинный перевод — экстрактивные методы суммаризации и работа с переводом/преобразованием текста.
- `LAB_3_NLP_done (2).ipynb`: Суммаризация абстрактов статей — предобработка, лемматизация и экстрактивная суммаризация (TextRank/sumy).
- `XAI.ipynb`: Объяснимость моделей — применение SHAP для глобальной и локальной интерпретации результатов классификации.

Структура и использование
- Все работы оформлены как Jupyter ноутбуки (`.ipynb`). Внутри каждого ноутбука есть описание задачи, использованных методов и основные результаты — открывайте соответствующий файл, чтобы получить подробности по каждому заданию.
